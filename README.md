# moomoo-style Trading App (Prototype)

A mobile-styled **web prototype** that recreates the look and feel of the
[moomoo — Invest & Trade](https://play.google.com/store/apps/details?id=com.moomoo.trade.ca)
app from its Play Store screenshots. Built with **React + TypeScript + Vite**.

> ⚠️ **Educational prototype only.** This is *not* a real brokerage. It places
> no real orders, holds no funds, and is not affiliated with Moomoo /
> Futu. All market data is **simulated** locally — no network calls, no API
> keys. A real regulated broker (order execution, custody, CIRO/CIPF
> membership) is a licensed financial institution, not something this repo
> provides.
>
> _(The original PartCrafter research README is preserved as
> [`README.partcrafter.md`](./README.partcrafter.md).)_

## What's implemented

Four screens matching the marketing shots, switchable from the bottom nav, with
a symbol switcher in the header (NVDA, TSLA, AAPL, MSFT, AMD, SHOP, RY, AMZN):

| Screen | Recreates |
| --- | --- |
| **AI Broker** | "Hi, I'm Moomoo AI" chat with suggestion chips, Daily/Weekly Brief, Key Events with source counts, and Trading Data commentary. A small canned intent-router (`src/data/ai.ts`) answers questions from the simulated data. |
| **Insights** | Consensus Rating badge (Strong Buy) with Buy/Hold/Sell bars, Short Sale Analysis volume bars + price line, and a candlestick mini-chart. |
| **Markets** | "Map the Market" — candlestick chart with MA5/MA20/MA30 overlays, charting toolbar, Daily/Weekly/Monthly/Quarterly timeframes, and the Pattern Finder grid. |
| **Level 2** | Real-time-ish order book: quote header, bid/ask ratio bar, cumulative depth chart, and a 12-level ARCA/NSDQ/… bid–ask ladder that **refreshes every 0.3s**. |

### How the "market" works

Everything is generated by a small seeded engine in `src/data/market.ts`:

- Deterministic PRNG (mulberry32) seeded per symbol so charts are stable across
  reloads but differ per ticker.
- OHLC candle series with SMA overlays, day high/low/volume, and a live Level-2
  book that mutates on a tick counter.

To make it a *real* app you would swap two modules:
`src/data/market.ts` → a live quote/candle API, and `src/data/ai.ts` → a real
LLM client. The UI wouldn't change.

## Run it

```bash
npm install
npm run dev      # http://localhost:5173
```

Build for production:

```bash
npm run build
npm run preview
```

## Project layout

```
src/
  App.tsx              # shell: header, symbol switcher, bottom nav
  data/
    market.ts          # simulated quotes, candles, Level-2 book
    ai.ts              # canned "Moomoo AI" brief + Q&A
  components/
    CandleChart.tsx    # hand-rolled SVG candlestick + moving averages
  screens/
    AIBroker.tsx
    Insights.tsx
    MarketMap.tsx
    Level2.tsx
  styles.css
```
